# Plan: Página interna con app Shiny embebida en iframe

## Objetivo

Convertir el enlace de menú "Buscar" (actualmente un link externo a la app Shiny) en una
página interna del blog que tenga el header y footer habituales, con la app Shiny embebida
en un `<iframe>`.

## ¿Es posible?

Sí. El archivo `layouts/_default/baseof.html` demuestra que **cualquier** layout del sitio
hereda automáticamente el header y footer:

```html
{{- block "header" . }}{{- partial "header.html" . -}}{{- end }}
{{- block "main" . }}{{- end }}
{{- block "footer" . }}{{- partial "footer.html" . -}}{{- end }}
```

Solo hay que definir el bloque `main` en un layout personalizado, y el iframe quedará
envuelto por la navegación y el pie de página igual que cualquier otra página del sitio.

---

## Archivos a crear / modificar

### 1. Crear `content/buscar/_index.md` *(nuevo)*

Página de sección mínima. Hugo la usará para generar la ruta `/buscar/`.

```yaml
---
title: "Buscar"
description: "Buscador de posts y tutoriales del blog"
---
```

### 2. Crear `layouts/buscar/list.html` *(nuevo)*

Layout personalizado que define el bloque `main` con el iframe.
Hugo lo selecciona automáticamente para la sección `/buscar/`.

```html
{{ define "main" }}
<main class="page-main pa4" role="main">
  <section class="page-content center" style="max-width: 1100px;">
    <h1 class="f1 lh-solid mb1 fw4">{{ .Title }}</h1>
    {{ with .Description }}<p class="f5 measure lh-copy mt0 mb3">{{ . }}</p>{{ end }}
    <iframe
      src="https://bastianoleah.shinyapps.io/buscador/"
      style="width: 100%; height: 85vh; border: none; border-radius: 4px;"
      title="Buscador de posts"
      loading="lazy">
    </iframe>
  </section>
</main>
{{ end }}
```

**Detalles de estilo del iframe:**
- `width: 100%` — ocupa todo el ancho disponible
- `height: 85vh` — 85% del alto del viewport (la app será visible sin scroll excesivo)
- `border: none` — sin borde
- `loading="lazy"` — carga diferida para no ralentizar la página

### 3. Editar `config.toml` *(modificar)*

Cambiar las dos entradas del menú "Buscar" (header y footer) de la URL externa a la ruta interna:

**Antes:**
```toml
url = "https://bastianoleah.shinyapps.io/buscador/"
```

**Después:**
```toml
url = "/buscar/"
```

Afecta las líneas:
- `[[menu.header]]` → "Buscar" (weight 7)
- `[[menu.footer]]` → "Buscar"

---

## Notas

- No se toca ningún layout existente ni el tema.
- El menú "Buscar" en header y footer ahora apuntará a `/buscar/` en vez de salir del sitio.
- La app Shiny sigue viviendo en shinyapps.io; solo se embebe aquí vía iframe.
- Si en el futuro se quiere agregar texto introductorio o instrucciones sobre el buscador,
  basta con escribirlo en `content/buscar/_index.md` y adaptar el layout para mostrar
  `.Content` (actualmente no está incluido para mantenerlo limpio).
