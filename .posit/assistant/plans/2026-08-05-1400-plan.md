# Plan: Tutorial de `{mapgl}` para R
`content/blog/mapas_mapgl/index.qmd`

## Contexto

Tutorial exhaustivo sobre `{mapgl}` siguiendo el estilo y estructura de los tutoriales de mapas existentes (`mapas_sf`, `mapas_hexagonales`, `mapas_bivariados`). 

El público es hispanohablante, con enfoque en datos de Chile, y el autor no es experto en el paquete.

## Temas de `{mapgl}` a cubrir (de la documentación oficial)

### Imprescindibles para un tutorial exhaustivo
1. **Instalación y primer mapa** — `maplibre()` vs `mapboxgl()`, diferencias (gratis vs API key)
2. **Estilos de mapa base** — `carto_style()`, `maptiler_style()`, `openfreemap_style()`, `basemap_style()`
3. **Vista rápida** — `maplibre_view()` para previsualizar datos sf
4. **Capas (layers)** — el concepto source → layer
   - `add_fill_layer()` — polígonos (coropletas)
   - `add_line_layer()` — líneas
   - `add_circle_layer()` — puntos
   - `add_heatmap_layer()` — mapas de calor
   - `add_fill_extrusion_layer()` — extrusiones 3D
   - `add_markers()` — marcadores simples
5. **Escalas de color y clasificación**
   - `interpolate_palette()` — escala continua automática
   - `step_quantile()`, `step_jenks()`, `step_equal_interval()` — clasificación categórica
   - `interpolate()`, `step_expr()`, `match_expr()` — expresiones manuales
6. **Tooltips y popups** — `tooltip`, `popup`, HTML con `concat()` / `get_column()`
7. **Hover effects** — `hover_options`
8. **Leyendas** — `add_legend()`, `add_continuous_legend()`, `add_categorical_legend()`, `legend_style()`
9. **Controles** — navegación, escala, pantalla completa, reseteo
10. **Cámara** — `center`, `zoom`, `bounds`, `fit_bounds()`, `fly_to()`

### Incluir brevemente
11. **Comparar mapas** — `compare()` (el autor quiere probarlo)

### Excluidos (para tutoriales futuros)
- Shiny (tutorial aparte)
- Story maps
- Mapas bivariados (ya cubierto en mapas_bivariados)
- Turf.js
- Flow maps
