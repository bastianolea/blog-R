title: Análisis de texto
description: |
  El análisis de texto son el conjunto de herramientas y metodologías relacionadas a extraer información y conocimiento a partir de extensos conjuntos de textos, como libros, artículos, páginas de internet, entrevistas y más. Usando metodologías estadísticas y herramientas de programación en R se pueden [procesar textos](/tags/texto/) para detectar relaciones entre documentos, clasificar información, analizar sentimientos, extraer tendencias, y más. Relacionado con el [procesamiento de texto.](/tags/texto/)
