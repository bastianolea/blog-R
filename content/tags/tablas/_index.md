---
title: Tablas
description: |
  Existen varios paquetes para crear y exportar tablas de datos con R, como [el paquete `{gt}` para crear tablas HTML estáticas](/blog/tablas_gt/), `{DT}` para tablas HTML interactivas, `{openxlsx2}` para crear tablas Excel, y más! Con estas herramientas puedes convertir un output o una base de datos ne una tabla personalizada y presentable para integrar en reportes o aplicaciones web.
