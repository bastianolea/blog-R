description: |
  Publicaciones sobre extracción automática de datos desde sitios web usando R. Web scraping es el conjunto de técnicas computacionales que permiten extraer datos e información alojada en páginas web, de manera automatizada. Como R es un lenguaje enfocado en el análisis de datos, cuenta con todas las herramientas para extraer, limpiar, procesar y automatizar la extracción de datos desde la web. Para iniciarte en el web scraping, te recomiendo [revisar este tutorial](/blog/web_scraping/).
